A monorepo-style portfolio that demonstrates a working knowledge of multiple modern test automation stacks. The goal: when an interviewer asks "show me how you'd write a Page Object Model in Playwright" or "what does a Pact contract test look like in practice?", there's a real, runnable example I can point to.

The suites cover end-to-end UI testing in **Cypress** and **Playwright**, classic POM-style coverage in **Python + Selenium**, and consumer-driven contract testing with **Pact**. GitHub Actions wires everything up so each push runs the full set in CI.
